Comparison of sys.executable and sys.prefix: Global Run (python): sys.executable points to the system-wide Python installation (eg:C:\Python312\python.exe) and sys.prefix points to the global base path. uv Run (uv run): sys.executable and sys.prefix dynamically resolve directly to your isolated project virtual environment (.venv).   
How uv run Isolates Automatically: uv run eliminates manual activation scripts (activate.ps1 / source activate) by automatically detecting the .venv folder, synchronizing dependencies on the fly, and injecting the isolated virtual environment interpreter into the process execution path.
